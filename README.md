# FixFlow

Aplicativo mobile para gerenciamento de solicitações de manutenção.

O projeto está sendo desenvolvido como aplicação acadêmica utilizando
React Native, API REST e banco de dados.

## Objetivo

Centralizar e padronizar o registro e acompanhamento de solicitações
de manutenção, permitindo que usuários registrem ocorrências e que
administradores acompanhem e gerenciem os atendimentos.

## Tecnologias previstas

### Mobile

- React Native
- Expo
- TypeScript

### Backend

- Node.js
- Express
- TypeScript
- Prisma

### Banco de Dados

- SQLite

## Funcionalidades previstas

- Cadastro de usuários
- Login
- Controle de acesso por perfil
- Usuário comum
- Administrador
- CRUD de solicitações
- Upload de imagens
- Validação de imagens
- Acompanhamento de status
- API REST
- Persistência em banco de dados
